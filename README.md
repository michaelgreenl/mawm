# MAWM

> Multi-Agent-Workflow Management (MAWM)*

MAWM is a monorepo for building and distributing project-level agent workflows. It publishes `@mawm/cli` for installing and running bundled workflows inside a target project's `.mawm/` directory. Workspace packages under `packages/utils` and `packages/workflows/*` provide the shared prompt/tool inputs and built-in workflow assets that `@mawm/cli` ships.
