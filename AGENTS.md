# MAWM

> Multi-Agent-Workflow Management (MAWM)*

MAWM is a monorepo for building and distributing project-level agent workflows. It publishes `@mawm/cli` for installing and running bundled workflows inside a target project's `.mawm/` directory. Private workspace packages under `packages/core/*` and `workflows/core/*` provide the source state bundles, shared prompt/tool inputs, and built-in workflow assets that `@mawm/cli` ships.
